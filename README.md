# Crowded Sleep

**Brand:** Crowded Sleep  
**Moniker:** folds that show

A responsive, editorial landing page exploring sleep, collective identity, and individuality, with an interactive Partnerships budget calculator.

## Working model

**[Open the live Crowded Sleep prototype](https://crowdedsleep.edgeone.dev/)**

## Features

- Responsive layouts for mobile, tablet, laptop, and desktop
- Accessibility support including skip navigation, visible keyboard focus, semantic landmarks, and reduced-motion preferences
- Concept-led brand story and copywriting
- Partnerships budget calculator with four configurable categories:
  - Individual
  - Double Bed
  - Hammocks
  - Pillow Case
- Editable items, quantities, and unit costs
- Currency selection, target-budget comparison, and CSV export

## Source

The working model is maintained in [index.html](./index.html).

## Notes

The calculator uses user-entered estimates. It does not fetch supplier prices or include shipping, taxes, fabrication, or installation unless those are entered as line items. DM Sans is loaded from Google Fonts and therefore requires an internet connection; a system-font fallback is provided.
